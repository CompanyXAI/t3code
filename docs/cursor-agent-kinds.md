# Cursor agent kinds and resume capability

T3 resumes a provider thread only through an official, documented session id (same rule as Codex `thread/resume` and Claude `--resume`). For Cursor that is the `@cursor/sdk` agent id (`agent-*`), resumed under its original cwd with a Cursor **user** API key (CLI login is not accepted by the SDK).

| Kind                      | Where it lives                                                                     | cwd source                          | Imported into T3                                            | Native resume in T3                                | Why / gap                                                                                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------- | ----------------------------------------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SDK agent, local          | `~/.cursor/projects/*/sdk-agent-store/*/index.db`                                  | `workspace_ref`                     | yes                                                         | **yes** (`agent-*` id, original cwd, user API key) | Official SDK path.                                                                                                                                          |
| SDK agent, cloud          | Cursor backend                                                                     | repo/branch of the cloud run        | only agents started from T3                                 | **yes**, via SDK with the same API key             | Not discoverable locally.                                                                                                                                   |
| CLI chat (`cursor-agent`) | `~/.cursor/chats/<md5(cwd)>/<id>/{meta.json, store.db}`                            | `meta.json`                         | yes (store.db decoded)                                      | **no** (`agent_not_found` via SDK)                 | CLI chat ids are not SDK agent ids. `cursor-agent --resume <id>` exists but is a different runtime; not wired (decision pending).                           |
| IDE composer chat         | `%APPDATA%/Cursor/User/globalStorage/state.vscdb` (`composerData:*`, `bubbleId:*`) | `workspaceStorage/*/workspace.json` | yes, flagged `nativeResumeUnavailable: "cursor_ide_import"` | **no**                                             | The IDE sends the full history to Cursor's private server API each turn; no public resume API. Continuing = new SDK agent seeded with the imported history. |
| IDE subagent (Task)       | inside parent composer bubbles                                                     | parent composer                     | as tool rows of the parent                                  | **no**                                             | Not standalone sessions.                                                                                                                                    |
| Transcript JSONL          | `~/.cursor/projects/<slug>/agent-transcripts`                                      | unique forward slug match           | yes, unless a copy of an SDK/CLI chat                       | **no**                                             | Ids return `agent_not_found`.                                                                                                                               |

UI for IDE imports: badge above the composer ("IDE import · continues as new agent"), disabled resume control with tooltip, and a confirm dialog with a token estimate on first send.
